# Agent Pavlov: Operation Silent Cordon

A night-time stealth game made in Unity 6 that runs in the browser.

Slip into the Cordon-7 base, steal the disk from the crate behind HQ and get out through the gap in the north-east fence. Stay in the shadows, crouch, throw pebbles to lure guards away and take them down from behind. If they see you, they radio the alarm.

**Play:** open the GitHub Pages link of this repository in Chrome, Edge or Firefox on a computer (about 18 MB download). Phones work in landscape with touch controls.

**Controls:** WASD move, mouse camera, Shift run, C crouch, E action / takedown (hold to use), left mouse shoot, right mouse aim, R reload, G throw pebble, Esc pause.

Voices and sound effects: ElevenLabs. Alarm music: Suno. Characters and props: Quaternius (CC0).
