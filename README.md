# Agent Pavlov: The Silent Signal

A night-time stealth game made in Unity 6 that runs in the browser. Mission 01 of 10.

A signal from a missing agent leads to a radio base in the forest. Follow the ridge to the watchtower and cross the fence there, plant a tracker on the communications server in the yard behind HQ, copy the transmission log and get out through the gap in the north-east fence. Stay in the shadows, crouch, throw pebbles to lure guards away and take them down from behind. If they see you, they radio the alarm.

**Play:** open the GitHub Pages link of this repository in Chrome, Edge or Firefox on a computer (about 23 MB download). Phones work with touch controls and lighter graphics.

**Controls:** WASD move, mouse camera, Shift run, C crouch, E action / takedown (hold to use), left mouse shoot, right mouse aim, R reload, G throw pebble, Esc pause (graphics quality is in the pause menu).

Voices and sound effects: ElevenLabs. Alarm music: Suno. Characters and props: Quaternius (CC0).
